#  AI Concierge for Economic Times (ET Ecosystem Personalization Agent)

🔗 Live Demo

 [https://ai-concierge-for-et.vercel.app]

Overview

ET AI Concierge is a production-ready AI-powered conversational assistant that intelligently profiles users and recommends personalized financial products and services across the Economic Times ecosystem.

It transforms static content discovery into an **interactive, personalized user journey**.

Problem Statement

The Economic Times offers a wide ecosystem of services (ET Prime, ET Markets, financial services, masterclasses), but:

* Users discover only a small fraction of available services
* First-time users feel overwhelmed
* No intelligent personalization exists


 Solution

An **AI-driven concierge system** that:

* Profiles users in under 3 minutes
* Understands financial goals and intent
* Recommends relevant ET services dynamically
* Provides a personalized onboarding experience

Key Features

**Smart 3-Minute Profiling** — Quick conversational onboarding
**AI Recommendation Engine** — Intelligent service mapping
**Analytics Dashboard** — Real-time insights and tracking
**12+ ET Services Integration** — Full ecosystem coverage
 **Supabase Backend** — User data & conversation tracking
**Responsive UI** — Works across all devices
**Production Ready** — Optimized performance and deployment

Profiling Flow

The system asks 4 strategic questions:

1. **Profession** — Student / Investor / Professional
2. **Financial Goals** — Learning, wealth growth, protection
3. **Risk Profile** — Conservative / Moderate / Aggressive
4. **Income Range** — ₹5L to ₹50L+

System Architecture

```
User → Chat UI → Profiling Agent → Recommendation Engine → Response → Supabase DB
```
